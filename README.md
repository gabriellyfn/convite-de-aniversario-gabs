# 🍓 Convite de Aniversário Y2K — Moranguinho (22 anos)

Uma landing page interativa e nostálgica desenvolvida para o meu convite de aniversário de 22 anos, inspirada no tema clássico da **Moranguinho dos anos 2000**. O projeto combina elementos visuais retrô (estética Y2K) com desenvolvimento web moderno e responsivo.

---

## 🎨 Sobre o Projeto

O conceito visual da aplicação resgata a memória afetiva da festa de 1 ano de idade, trazendo uma releitura moderna em comemoração aos 22 anos. 

### Destaques Visual e UX:
- **Estética Y2K / Anos 2000:** Paleta baseada em tons de rosa, verde-menta e vermelho morango, com bordas arredondadas e cards estilizados.
- **Rolagem Suave (`scroll-behavior: smooth`):** Navegação fluida entre todas as seções do convite.
- **Nostalgia & Galeria:** Seção dedicada para fotos de infância e ilustrações da personagem.
- **Integração Externa:** Botão direto para rota no Google Maps e confirmação via WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da aplicação.
- **Tailwind CSS (via CDN):** Estilização ágil, responsiva e focada na paleta do tema.
- **Google Fonts:** Tipografia customizada para reforçar o estilo Y2K.
- **Git & GitHub Pages:** Versionamento de código e publicação do site.
